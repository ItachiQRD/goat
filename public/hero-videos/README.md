# Hero videos — storyboard

Placez ici les fichiers générés (MP4, 1080p ou 1440p, ~6–10 s, fond sombre #0a0a0a / #151515) :

| Fichier | Beat | Rôle |
|---------|------|------|
| `01-coding.mp4` | 01 — Le code | Développeur qui code |
| `02-commercial.mp4` | 02 — Le résultat | Site / Google → commercial qui convertit |

Recommandations techniques :
- Format : H.264 MP4, mute (le site mute déjà)
- Ratio : 16:9
- Pas de watermark
- Éviter le texte brûlé dans la vidéo (le site affiche les titres)
- Boucle propre (début/fin proches) pour un loop fluide

Les prompts complets sont dans la conversation / le README du projet.
