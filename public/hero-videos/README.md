# Hero video

Placez ici le montage unique :

| Fichier | Rôle |
|---------|------|
| `hero.mp4` | Montage (code → compétences → commercial) |

Recommandations :
- Format : H.264 MP4, mute (le site mute déjà)
- Ratio : 16:9, prévu pour les écrans d’au moins 1280 px de large
- Pas de watermark
- Éviter le texte brûlé (le site affiche les titres)
- Boucle propre pour un loop fluide

En dessous de 1280 px (mobile et tablette), le site n’affiche pas cette vidéo : un hero composé pour le format portrait prend le relais, et le fichier n’est pas téléchargé.

Les anciens fichiers `01-coding.mp4`, `02-commercial.mp4`, `03-morph.mp4` ne sont plus utilisés par le site.
